# 🏠 Smart House Price Analyzer
A Machine Learning web application developed using **Linear Regression** to predict house prices based on property features. This project was completed as part of the **SkillCraft Technology Machine Learning Internship (Task 1)**.
---
## 📌 Project Overview
The Smart House Price Analyzer estimates house prices using property attributes such as:
- Square Feet
- Bedrooms
- Bathrooms
- Parking Availability
- Location Rating
- Furnishing Type
- Property Age
The application provides an interactive dashboard, prediction system, analytics visualizations, and downloadable prediction reports.
---
## 🚀 Features
### 🏠 House Price Prediction
- Predict house prices instantly
- Interactive user inputs
- Real-time prediction using Linear Regression
### 📊 Dashboard
- Total Properties
- Average Property Price
- Maximum Property Price
- Model Accuracy (R² Score)
### 📈 Analytics
- House Price Distribution
- Area vs Price Analysis
- Correlation Heatmap
- Dataset Statistics
### 📥 Report Generation
- Download prediction reports as CSV files
