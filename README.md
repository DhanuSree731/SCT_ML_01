# House Price Prediction

Machine Learning project developed using Python, Scikit-Learn and Streamlit.

## Features
- House Price Prediction
- Linear Regression Model
- Prediction Accuracy
- Prediction History
- Data Visualization
- Download Prediction Report

## Technologies Used
- Python
- Pandas
- Scikit-Learn
- Matplotlib
- Streamlit

## Run Locally

pip install -r requirements.txt

streamlit run app.py
